# 📝 Notes Garden: Telegram-бот + Apple Design сайт с AI-ассистентом

Асинхронный персональный Telegram-бот на **Python (aiogram 3.x)** с сайтом в стиле **Apple Design**, базой данных **SQLite / PostgreSQL (SQLAlchemy 2.0)**, миграциями **Alembic** и встроенным **AI-ассистентом** для структурирования заметок и автоподбора тегов.

---

## 🌟 Главные возможности

1. **Интеллектуальный AI-ассистент заметок**:
   - Вы можете надиктовать или написать мысль впопыхах (с опечатками, словами вроде *«сахрони»*, *«запиши»*).
   - Бот удаляет мусорные слова, исправляет ошибки и превращает текст в **подробную, красивую карточку** с эмодзи-заголовком и пунктами к действию.
   - **Автоматические тематические теги**: бот сам определяет категорию (кино, книги, покупки, код, спорт, поездки, финансы) и выставляет точные хэштеги (`#кино`, `#планы`, `#покупки` и др.).
   - **Живой диалог**: бот отвечает вам персонально, подтверждая задачу в теплой дружелюбной манере.

2. **Поддержка бесплатных LLM API**:
   - **Groq API** (Llama 3.3 70B) — бесплатно, без карт, сверхбыстрый отклик (<0.5 сек).
   - **Google Gemini API** (Gemini 1.5/2.0 Flash) — бесплатно через Google AI Studio.
   - **OpenRouter** — бесплатные открытые модели с суффиксом `:free`.
   - **Встроенный автономный NLP-движок**: работает даже без интернета и без API-ключей, прямо из коробки!

3. **Apple Design сайт ([http://localhost:8080](http://localhost:8080))**:
   - Стеклянный акрил (Glassmorphism), анимации, темная и светлая темы.
   - Живой поиск (`⌘K` / `Ctrl+K`), фильтры по тегам и статусам.
   - **Синхронизация в реальном времени (SSE)**: отправленная в бот заметка появляется в открытом браузере за миллисекунды.
   - Работает и оффлайн при открытии `site/index.html`.

## 🔑 Подключение бесплатного AI API (по желанию)

Бот уже отлично работает на встроенном умном движке, но вы можете подключить мощную нейросеть **Llama 3.3 70B** или **Gemini** за 30 секунд абсолютно бесплатно:

### Вариант 1: Сверхбыстрый Groq (Рекомендуется)
1. Перейдите на [console.groq.com/keys](https://console.groq.com/keys) и войдите через Google/GitHub.
2. Нажмите **Create API Key** и скопируйте ключ вида `gsk_...`.
3. В файле `.env` вставьте:
   ```env
   AI_API_KEY=gsk_ваш_ключ_здесь
   AI_PROVIDER=groq
   AI_MODEL=llama-3.3-70b-versatile
   ```

### Вариант 2: Google Gemini
1. Перейдите на [aistudio.google.com](https://aistudio.google.com/) и нажмите **Get API key**.
2. В файле `.env` вставьте:
   ```env
   AI_API_KEY=AIzaSy...ваш_ключ_здесь
   AI_PROVIDER=gemini
   AI_MODEL=gemini-1.5-flash
   ```

Перезапустите бота — и ваши заметки будет структурировать топовая нейросеть!
